# Darky_nails - Landing Page
Landing page para un salón de uñas ficticio, tal landing page está creada como proyecto de portfolio, con el fin de mostrar el diseño responsive y la interacción con el frontend

**Live site** https://datatech800.github.io/darky_nails/

>**Nota:** Darky Nails es una marca ficticia creada solo con fines demostrativos

-  HTML5 
-  CSS3
-  JavaScript

<h2>Funcionalidades</h2>

-  Diseño responsive (Desktop/mobile)
-  Seccion de servicios y galería
-  Botón de contacto por medio de WhatsApp
